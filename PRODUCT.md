# Tonight

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Meetup hosts, student clubs, and small businesses making promotional event posters without design software, as described in idea.md.

## Product Purpose

Enter event details, choose a visual style, generate one portrait poster with Ideogram, and download the same image shown in the preview.

## Capabilities and Constraints

The user confirmed that the redesign keeps the single-page poster studio. Preserve event name, date/time display text, venue, optional description, Neon Nightlife, Retro Print, Minimal Editorial, generation, regeneration, and image download. Keep the last successful result on errors. Next.js with TypeScript and CSS Modules; server-only Ideogram credentials. No accounts, payments, saved gallery, or image editor. Results live in browser memory. Generated lettering needs review.

## Brand Commitments

Keep the name Tonight. The user wants a premium, distinctive interface and explicitly rejects generic AI UI styling. Visual implementation decisions are delegated through the UI improvement request; no exact palette or typeface is prescribed.

## Evidence on Hand

The existing application and backend are functional. Local Ideogram samples exist under .backend-artifacts. Neon and Retro samples have readable event details; the Minimal sample has extraneous small text and is unsuitable as a quality showcase. No customer testimonials, usage statistics, or pricing claims are supplied.

## Product Principles

- Let the poster demonstrate the product.
- Keep creating a poster a short, understandable task.
- Make sample artwork distinguishable from the user's generated result.
- Preserve honest loading, error, and output states.
